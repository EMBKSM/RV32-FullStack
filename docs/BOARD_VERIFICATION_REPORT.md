# RV32-FullStack — 보드 검증 리포트 (Board Verification Report)

- **생성일**: 2026-06-15
- **보드**: Zybo Z7-20 (Zynq-7000, xc7z020clg400-1)
- **경로**: PC → UART(115200 8N1) → Zynq PS 모니터(OCM) → AXI-Lite(0x4000_0000) → RV32 CPU → 레지스터 회신
- **방식**: GUI/Qt를 거치지 않는 **raw 시리얼** 직접 측정 (표시 계층과 무관한 하드웨어 실측)

## 2. 방법 (Methodology)

각 프로그램에 대해:

1. PC에서 **검증된 어셈블러**로 기계어 변환
2. PS 모니터 프로토콜(`r` 리셋 → `i` 명령적재 → `g` 실행)로 명령 메모리(PL BRAM)에 적재·실행
3. 실행 후 `D`(전 레지스터)·`c`(커밋 수)를 회신받아, **손계산 예상값과 1:1 대조**

예상값은 루프 전개·분기 추적·메모리 round-trip을 사람이 직접 계산했습니다. 한 레지스터라도 불일치하면 FAIL입니다. 검증은 PS 모니터 프로토콜을 통한 raw 시리얼 자동화로 수행했습니다.

## 4. 무작위 회귀 (ISS 골든 모델, 100개)

손계산이 비현실적인 대량 검증을 위해 Python으로 RV32I **레퍼런스 ISS(골든 모델)**를 구현하고 무작위 프로그램 100개를 생성했습니다. 각 프로그램(12~22개 무작위 명령 — ALU·시프트·lui·auipc·load/store, 무작위 레지스터 의존)을 **보드와 ISS에서 각각 실행**해 32개 레지스터 전체를 비교했습니다. 무작위 레지스터 의존성은 파이프라인의 **forwarding·load-use 해저드**를 자연스럽게 스트레스합니다.

**결과: 100 / 100 PASS** — 보드의 아키텍처 상태가 골든 모델과 100% 일치. (난수 seed=20260615 고정으로 재현 가능)

## 5. 커버리지

- **산술/논리/시프트**: add sub and or xor sll srl sra slt sltu, addi/xori/ori/andi/slti/sltiu, slli/srli/srai
- **제어흐름**: 분기 6종(beq bne blt bge bltu bgeu, taken/not-taken), jal/jalr, 단일·중첩 루프
- **메모리**: sw/sh/sb, lw/lh/lb/lhu/lbu (부호·제로확장), 배열 합·복사·조건 누적
- **알고리즘 패턴**: GCD, Fibonacci, 곱셈(반복덧셈), 나눗셈(몫·나머지), popcount, clamp, signum, 최댓값, XOR swap, 임계값 누적

별도 회귀(`_verify_all.py`)에서 RV32I **39개 명령 전부 개별 PASS**도 확인했습니다.

## 6. 범위 밖 / 별도 항목

- **DDR-백킹 실행**: 현재 비트스트림에 미구현(명령/데이터 메모리는 PL BRAM 사용). PS DDR 최상위 바이트 이상은 `ps7_init`(DDR 캘리브레이션) 미초기화 가능성이 있어, 본 검증 범위 밖으로 보류.
- **보드 스위치 2비트**: 구현 I/O 리포트상 핀 배치(G15/P15/W13/T16)·제약은 정상 확인됨 → 코어 기능과 무관. 별도 보드/비트스트림 점검 필요.

---

## 7. 결론

PC에서 어셈블리를 입력해 FPGA의 RV32 CPU가 **실행 → 메모리 접근 → 제어흐름 → 결과 회신**하는 전 경로가 보드에서 raw로 **완전히 검증**되었습니다. 다양한 실제 알고리즘 20종과 명령 39종 모두 예상값과 일치하므로, **코어 시스템은 정상 동작**합니다.
